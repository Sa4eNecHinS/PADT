# PADT — Personal Activity Daily Tracker

**PADT** — daemon для отслеживания пользовательской активности в Linux с Hyprland. 
Цель проекта - собирание статистики использования своего пк. Основное отличие от других трекеров - определение контекста работы. мне недостаточно знать, что я провел 3 часа в терминале. важно знать что я делал, в какой директории был, какие файлы изменял.  


## Основные задачи

- **Автоматический сбор активности:** работа в фоновом режиме без необходимости вручную запускать и останавливать отслеживание.
- **Отслеживание приложений:** определение активного окна и времени взаимодействия с ним.
- **Учёт рабочих пространств:** сбор статистики использования виртуальных рабочих столов.
- **Определение контекста:** отслеживание процессов, рабочих директорий и посещаемых сайтов.
- **Хранение истории:** сохранение активности для последующего просмотра и анализа.
